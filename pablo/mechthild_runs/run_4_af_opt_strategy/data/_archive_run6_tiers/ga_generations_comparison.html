run_6: GA Generation Budget Comparison (Batch vs. Sequential)

0. Setup and Motivation

Model & objective. A plain SingleTaskGP fitted directly on yield (grover / map / map featurization, ARD-RBF kernel, Hvarfner LogNormal lengthscale prior, Normalize + Standardize). The AF is qLogNEI (512 MC samples), maximized to produce a batch of q=6 candidates. This is the same surface used in the run_5 stability run (archived at data/_archive_lcm_cs_run/).

Why this run. run_5 showed that the continuous L-BFGS refine consumed 70–85% of wall time (57 restarts / 2900 raw samples), leaving the GA — which selects the discrete catalyst×solvent×base set — generation-starved. run_6 pins the refine to a minimum (3 restarts / 128 raw samples) and redirects the runtime budget to GA generations, asking: how far does discrete-set quality improve as generation count grows?

Grid. Two strategies × 3 effort tiers × 30 reps = 180 optimizations. Tiers vary only ga_n_evals (= generations × pop); pop and MC are fixed within each strategy.

  • Batch GA: jointly optimizes all 6 candidates. Pop = 256, 512 MC. Tiers: 150 k / 230 k / 300 k evals (≈ 750 / 1150 / 1500 generations).
  • Sequential GA: greedy one-at-a-time, 6 steps per opt. Pop = 128/step, 512 MC. Tiers: 40 k / 60 k / 80 k evals per step (≈ 313 / 469 / 625 generations/step).

L-BFGS refine: 3 restarts / 128 raw samples, identical across all cells.

2. Effect of More Generations (Tier 0 → 1 → 2)

More generations do not improve median acq value — for either strategy. Batch median: −2.213 (T0) → −2.232 (T1) → −2.243 (T2). Sequential median: −2.295 (T0) → −2.297 (T1) → −2.301 (T2). Both trends are flat-to-slightly-worse, suggesting the GA has already converged by tier 0 (~750 generations for batch, ~313 generations/step for sequential). The standard deviation also grows slightly with tier for batch (0.084 → 0.111), indicating more budget does not reduce variance.

Interpretation: at the current population sizes (pop 256 for batch, pop 128 for sequential), the GA explores the discrete space as well as it can in the first tier; additional generations recycle the same promising discrete agents without discovering new ones. The marginal return per extra 100k evals is effectively zero.

The refine is now correctly subordinate: GA takes 83–92% of batch runtime and 77–89% of sequential runtime. In absolute terms the refine is a near-constant overhead (3 restarts × 128 raw samples). The refine gain over GA output is negligible: pre- vs post-refinement delta on qLogNEI is < 0.002 log units across all batch tiers.

4. Reproducibility

Sequential GA is more reproducible than batch. Per-tier standard deviation: batch 0.084 / 0.105 / 0.111 vs sequential 0.049 / 0.059 / 0.102. Sequential's lower-dimensional per-step problem is easier to solve consistently; batch faces a harder joint q=6 landscape and occasionally gets trapped in a worse discrete attractor, producing the longer lower tail seen in the CDFs.

5. Discrete Choice Convergence (Batch)

Batch GA consistently selects 2–3 unique discrete combos per 6-candidate output (mean 2.1–2.2 across tiers). This near-constant count confirms that the GA reliably concentrates on 2–3 dominant catalyst×solvent×base groups regardless of how many generations it runs.

6. Efficiency: Acq Value vs Wall Time

The scatter makes the efficiency story clear: batch cluster (top-left, blue) achieves better acq values at lower wall times than sequential (bottom-right, orange). All three batch tiers outperform all three sequential tiers in median acq, and batch tier 0 is cheaper than sequential tier 0. There is no crossover: sequential never catches batch regardless of generation budget.

7. Conclusions

  1. Batch GA wins outright. It achieves 0.06–0.08 log-NEI units higher acquisition value in less wall time. Sequential's 6-step serial structure adds overhead without offsetting gain.
  2. GA has converged at tier 0. Both strategies plateau by ~750 (batch) / ~313 (sequential) generations; additional budget is wasted. For future runs, tier 0 settings are sufficient.
  3. The population, not the generation count, is the next lever. With the GA saturating its generation budget early, increasing population diversity (more agents from different starting points) is the natural next experiment to probe whether undiscovered discrete attractors exist.
  4. Reproducibility favors sequential (lower std), but the absolute quality deficit makes sequential the inferior choice for production runs.
  5. Discrete convergence is robust. Batch GA locks onto 2–3 discrete combos consistently, with one dominant winner. This is not improved by more generations.
