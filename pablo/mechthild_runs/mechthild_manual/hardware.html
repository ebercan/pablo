    Hardware

    This page gives an overview about the hardware of mechthild. Overall we have 82 nodes for computations available.

    CPU Nodes

    This are the standard CPU nodes known from the first stage of mechthild.

    • Hostnames: node001-node040, node045-node050

    • CPU: 2x Intel Xeon Silver 4110 (Skylake)

      • 8 Cores per CPU (64Kb L1 Cache, 1024kb L2 Cache)
      • Clockrate: 2.1 GHz (3.0 GHz max)
      • 12MB Shared L3 Cache per CPU

    • Memory: 192GB DDR4 with ECC

    • Network:

      • OmniPath, 25 GBit/s
      • Service Network, 1 GBit/s
      • IPMI Network, 100MBit/s

    • diskless

    Big-Memory Nodes

    • Hostnames: bigmem121-bigmem130

    • CPU: 2x Intel Xeon Silver 4110 (Skylake)

      • 8 Cores per CPU (64Kb L1 Cache, 1024kb L2 Cache)
      • Clockrate: 2.1 GHz (3.0 GHz max)
      • 12MB Shared L3 Cache per CPU

    • Memory: 384GB DDR4 with ECC

    • Network:

      • OmniPath, 25 GBit/s
      • Service Network, 1 GBit/s
      • IPMI Network, 100MBit/s

    • diskless

    GPU Nodes - Tesla P100

    • Hostnames: gpu01-gpu05

    • CPU: 2x Intel Xeon Gold 6130 (Skylake)

      • 16 Cores per CPU (64Kb L1 Cache, 1024kb L2 Cache)
      • Clockrate: 2.1 GHz (3.7 GHz max)
      • 22MB Shared L3 Cache per CPU

    • GPUs: 2x NVidia P100

    • Memory: 192GB DDR4 with ECC

    • Network:

      • OmniPath, 25 GBit/s
      • Service Network, 1 GBit/s
      • IPMI Network, 100MBit/s

    • diskless

    GPU Nodes - Telsa A100

    • Hostnames: gpua01-gpua05

    • CPU: 2x AMD EPYC 7452 32-Core Processor (Zen2)

      • 32 Cores per CPU (64Kb L1 Cache, 512kb L2 Cache)
      • Clockrate: 2.35 GHz
      • 128MB Shared L3 Cache per CPU

    • GPUs: 4x NVidia A100(gpua01), 2x NVidia A100 (gpua02-gpua05)

    • Memory: 512GB DDR4 with ECC

    • Network:

      • OmniPath, 25 GBit/s
      • Service Network, 1 GBit/s
      • IPMI Network, 100MBit/s

    • Local temporary storage on /scratch (1.8TB)

    GPU Nodes - Telsa H100

    • Hostnames: gpuh01-gpuh12

    • CPU: 2x INTEL(R) XEON(R) PLATINUM 8562Y+ (Emerald Rapids)

      • 32 Cores per CPU (80kB L1 Cache, 2MB L2 Cache)
      • Clockrate: 2.8 GHz []
      • 60MB Shared L3 Cache per CPU

    • GPUs: 4x NVidia H100(gpuh11, gpuh12), 2x NVidia H100 (gpuh01-gpuh10)

    • Memory: 512GB DDR5 with ECC (gpuh01-gpuh10), 1536GB DDR5 with ECC (gpuh01-gpuh10)

    • Network:

      • OmniPath, 25 GBit/s
      • Service Network, 1 GBit/s
      • IPMI Network, 100MBit/s

    • Local temporary storage on /scratch (7TB) only on gpuh11 and gpuh12

    Login Node

    • Hostname: mechthild, mechthild01

    • CPU: INTEL(R) XEON(R) GOLD 6526Y (Emerald Rapids)

      • 16 Cores per CPU (80kB L1 Cache, 2MB L2 Cache)
      • Clockrate: 2.8 GHz
      • 37.5MB Shared L3 Cache per CPU

    • Memory: 512GB DDR5 with ECC

    • Network:

      • OmniPath, 25 GBit/s
      • Service Network, 1 GBit/s
      • IPMI Network, 100MBit/s
      • Uplink to the Institute Network: 10 GBit/s

    • This is the central login node for the cluster, all user interactions are performed using this server.

      • Clockrate: 2.8 GHz

    Storage

    The central storage is a BeeGFS with 128TB. It provides parallel access to

    • /mechthild/home, the home directory on the cluster
    • /mechthild/data, shared data on the cluster
    • /mechthild/software, software and libraries shared over all nodes. (read only)

    It is connected using 10 Gbit/s to the Institute's network and could be access from the LINUX desktop computers via NFS.

    Networking

    • Service Network, 1 Gbit/s network to login on the nodes and boot the diskless nodes. It is realized using normal ethernet.
    • IPMI Network, 100Mbit/s network to monitor the nodes and to get a remote access to screen and keyboard.
    • OmniPath network. 25 Gbit/s at the nodes. 1 TB/s between switches.
