What
A 2D molecular-graph encoder whose attention Q, K, V come from message-passing nets, run twice (a node view and an edge view), pretrained on 11M ZINC15 + ChEMBL molecules by predicting masked 1-hop context labels and RDKit functional-group motifs.
2026 status
Historically important, no longer competitive as a representation. Its SOTA claims leaned on concatenated RDKit 2D descriptors and an optimistic split protocol; independent frozen-embedding benchmarks place it significantly below ECFP. Weights still download and run with patches.
For PABLO
grover_pca leads the elimination sweep (baseline gem 0.193, 1st of 50), but on the 161-catalyst library its leading embedding PCs are 80 to 95 % linearly predictable from RDKit 2D descriptors. Before the paper claims a pretraining effect, add an rdkit2d level as the ablation. Details in the last section.

Input to output, step by step

Shapes use \(n\) atoms, \(m\) bonds, hidden size \(d\) (800 base, 1200 large), 4 heads. Two directed hidden states exist per bond, \(h_{vw}\neq h_{wv}\).

  1. SMILES → RDKit graph. Atom features: type (100-way), formal charge, bond count, chirality, H count, mass/100, aromaticity, hybridization. Bond features: type, stereo, in-ring, conjugated. x_v ∈ ℝ^128 per atom, e_uv ∈ ℝ^12 per bond (paper Tables 4-5)
  2. Linear embedding. Project raw features to \(d\), separately for the two streams. node view: H ∈ ℝ^(n×d) · edge view: H_E ∈ ℝ^(2m×d)
  3. dyMPN produces Q, K, V. Per head, three separate message-passing nets run \(K_l\) hops, with \(K_l\) resampled every epoch from a truncated normal \(\phi(\mu{=}6,\sigma{=}1;[3,9])\). The edge view passes messages on the line graph with reverse-bond subtraction (D-MPNN style). Q, K, V ∈ ℝ^(n×d) per head (edge view: ℝ^(2m×d))
  4. Multi-head self-attention over all atoms of the molecule (a complete graph), then LayerNorm with residual. H̃ ∈ ℝ^(n×d) (edge view: ℝ^(2m×d))
  5. Aggregate2Node and Aggregate2Edge. Each view sums its attended states onto atoms and onto directed bonds, concatenates the original input features (the single long-range residual), then FFN + LayerNorm. each view emits one atom set and one bond set → 4 embedding sets
  6. Readout. Pretraining: task heads on atoms, bonds and mean-pooled graph vectors. Fine-tuning: self-attentive pooling, concatenated with 200 RDKit 2D descriptors, then an MLP per view. Fingerprint mode: mean-pool all four sets and append the 200 descriptors. fingerprint: 4·d + 200 = 5000 for GROVER-large

The layers

dyMPN (inside every Q, K, V producer)

\[ \begin{gathered} m_v^{(k)}=\sum_{u\in\mathcal N_v}\operatorname{AGG}\big(h_v^{(k-1)},h_u^{(k-1)},e_{uv}\big),\qquad h_v^{(k)}=\sigma\big(W m_v^{(k)}+b\big),\\ k=1,\dots,K_l,\qquad K_l\sim\phi(6,1;[3,9]) \end{gathered} \]

Weights are shared across hops within the iteration (\(L=1\) iteration in the released models). Resampling \(K_l\) per epoch trains one set of weights over a random receptive field, which acts as a regulariser: in the ablation it slightly raises training loss and lowers validation loss.

Graph multi-head attention

\[ \begin{gathered} Q_i=\mathrm{dyMPN}^{Q}_i(H),\quad K_i=\mathrm{dyMPN}^{K}_i(H),\quad V_i=\mathrm{dyMPN}^{V}_i(H),\\ \mathrm{head}_i=\operatorname{softmax}\!\Big(\tfrac{Q_iK_i^{\top}}{\sqrt d}\Big)V_i,\qquad \tilde H=\operatorname{LN}\big(H+\big[\mathrm{head}_1\Vert\cdots\Vert\mathrm{head}_4\big]W^{O}\big) \end{gathered} \]

No positional or structural bias enters the attention logits. All graph information in \(QK^\top\) comes from the fact that each query and key already summarises a ~6-hop neighbourhood.

Aggregate2Node / Aggregate2Edge and the long-range residual

\[ m_v^{\text{node}}=\sum_{u\in\mathcal N_v}\tilde h_u,\qquad m_{vw}^{\text{edge}}=\sum_{u\in\mathcal N_v\setminus w}\tilde h_u,\qquad z=\operatorname{LN}\big(\mathrm{FFN}([\,x\,\Vert\,m\,])\big) \]

The input features \(x\) skip the whole block and are concatenated right before the FFN. One long residual replaces the per-sublayer residuals of a vanilla Transformer; the paper argues this limits over-smoothing of the message passing. The edge view applies the same two aggregators to \(\tilde h_{uv}\), which is why the model ends with four embedding sets.

Self-supervision

Contextual property (atoms and bonds)

For a target atom, take its \(k{=}1\) subgraph, count (neighbour element, bond type) pairs, sort alphabetically and use the string as a class label, e.g. C_N-DOUBLE1_O-SINGLE1. Bonds get the analogous label, e.g. DOUBLE_C_SINGLE1_N-SINGLE1.

2518 atom classes and 2686 bond classes over the corpus. 15 % of atoms and bonds are masked per molecule; a linear softmax head predicts the class from the embedding (NLL).

Graph-level motifs

RDKit detects 85 functional groups (the fr_* fragment counters). The graph vector (mean readout) predicts their presence as an 85-way multi-label BCE problem.

Labels cost one substructure match per molecule and need no experiment, so the graph-level task avoids the negative transfer Hu et al. (2019) saw with supervised graph pretraining.

Released-code objective (the paper does not state the sum explicitly), with both views predicting everything and a consistency term tying them together:

\[ \begin{aligned} \mathcal L={}&\sum_{\text{view}\in\{\text{atom},\text{bond}\}}\Big[\mathcal L^{\text{ctx}}_{\text{atom}}+\mathcal L^{\text{ctx}}_{\text{bond}}+\mathcal L^{\text{motif}}\Big]\\ &+\lambda\sum_{t\in\{\text{atom},\text{bond}\}}\big\lVert\hat y^{\text{ctx},t}_{\text{atom-view}}-\hat y^{\text{ctx},t}_{\text{bond-view}}\big\rVert_2^2 +\big\lVert\hat y^{\text{motif}}_{\text{atom-view}}-\hat y^{\text{motif}}_{\text{bond-view}}\big\rVert_2^2 \end{aligned} \]

Adam, lr 1.5·10⁻⁴ with Noam warm-up, 500 epochs, PReLU, dropout 0.1, 10 % of the 11M molecules held out for model selection.

Fine-tuning versus fingerprint mode

Fine-tuning (what the paper benchmarks). Each view's atom embeddings \(H\) go through a self-attentive readout, the 200 RDKit 2D descriptors are appended, and two MLPs predict the target:

\[ \begin{gathered} S=\operatorname{softmax}\big(W_2\tanh(W_1H^{\top})\big),\qquad g=\operatorname{Flatten}(SH),\\ \mathcal L=\ell(p_{\text{node}},y)+\ell(p_{\text{edge}},y)+\lambda_{\text{diss}}\lVert p_{\text{node}}-p_{\text{edge}}\rVert_2 \end{gathered} \]

Hyperparameters come from a 300-configuration random search per dataset, all encoder weights are updated.

Fingerprint mode (what a frozen featurizer uses). No training. The code mean-pools the four embedding sets and, if a features file is passed, appends the descriptors:

\[ \mathrm{fp}=\big[\overline{H}_{a\leftarrow a}\,\Vert\,\overline{H}_{a\leftarrow b}\,\Vert\,\overline{H}_{b\leftarrow a}\,\Vert\,\overline{H}_{b\leftarrow b}\,\Vert\,r_{\text{RDKit200}}\big]\in\mathbb R^{4d+200} \]

The frozen embedding was never optimised for a mean readout on a downstream target; it inherits only what the context and motif tasks forced into it.

Why it counts as a graph transformer

A Transformer layer is message passing on the complete graph with learned, input-dependent edge weights \(\alpha_{uv}=\operatorname{softmax}_u(q_v^\top k_u/\sqrt d)\). A graph transformer must reinject the real topology somewhere. The families differ in where:

ModelWhere the molecular graph enters
GROVER (2020)In the tokens: Q, K, V are outputs of MPNNs, so each token is a local subgraph summary. Attention itself is unbiased and global.
Graphormer (2021)In the logits: shortest-path, centrality and edge-path biases added to \(q^\top k\). Tokens are raw atoms.
GraphGPS (2022)In parallel: an MPNN layer and a global attention layer per block, outputs summed, plus positional encodings.
Uni-Mol, Transformer-MIn a pair representation built from 3D distances (and 2D paths for Transformer-M) biasing the logits.

GROVER's version is the "bi-level" idea from the paper: local structure from the dyMPN, long-range atom-atom interaction from attention. The ablation "GROVER w/o GTrans" (dyMPN feeding a plain Transformer) trained worst of the three variants, and on a 600K-molecule toy set GTransformer beat GIN and MPNN backbones at matched 38M parameters.

Why it works, and what survived later audits

Mechanisms the design relies on

  • Richer masked targets. Predicting the atom type alone (Hu et al.) is a low-entropy task dominated by carbon. The 2518-way context label forces the embedding to carry the element, its neighbours and the bond orders, which is closer to what 2D structure-property relations use.
  • Chemistry-aware graph target. The motif task pushes functional-group content into the graph vector without labels. This is effectively distillation of RDKit substructure rules.
  • Receptive-field randomisation (dyMPN) as a regulariser, and the long-range residual against over-smoothing.
  • Scale. 100M parameters on 11M molecules was, in 2020, the largest molecular GNN pretraining run.

Claims versus later evidence

The architectural ideas are sound. The size of the reported benefit came mostly from protocol and descriptors, and the learned part adds little when labels are scarce and the downstream model is simple.

Where it has predictive power

The pretraining corpus (ZINC15 + ChEMBL) and targets (1-hop topology counts, RDKit functional groups) define the domain. The encoder sees no coordinates, no conformers, no charges beyond formal charge and no electronic structure.

Strong

  • Drug-like organic molecules built from H, C, N, O, S, P and halogens.
  • Properties that are close to additive in functional groups: aqueous solubility, logD, hydration free energy, membrane permeability, many toxicity and ADMET endpoints.
  • Low-to-medium data classification where a fine-tuned model can lean on the descriptor concatenation.
  • Small rigid QM targets (QM7/QM8) were competitive in the paper, because 2D topology nearly fixes the geometry there.

Weak or out of domain

  • Conformation-controlled properties (sterics around a reactive centre, buried volume, flexible binding).
  • Electronic properties that differ between topologically similar molecules: σ-donor strength, redox potentials, HOMO/LUMO trends in a congeneric series.
  • Activity cliffs and stereochemistry beyond the chirality tag.
  • Organometallics, ionic multi-fragment species, radicals and carbenes; a mean readout mixes cation and counter-ion atoms.
  • Reactions and processes: it embeds one molecule. Temperature, concentration, mixtures and reaction centres are invisible to it; those must be modelled outside the embedding.

Is it still usable in 2026?

Technically, yes. Code (tencent-ailab/grover) is unmaintained, but checkpoints download and fingerprint mode runs on current PyTorch with two patches already in features/foundation.py: missing args added to the pickled Namespace, and TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1 for torch ≥ 2.6.

As a state-of-the-art choice, no. The field moved to 3D-aware pretraining, descriptor-supervised pretraining and, since 2025, in-context predictors. The ideas that worked in GROVER (descriptor-derived targets, MPNN plus attention) were refined by its successors.

Would it be useful for PABLO?

It already is in use, so the useful question is what the grover signal actually is. Read from the repo on 30.09.2026 (features/foundation.py, features/dim_reduction.py, data/featurizations/grover*, results/gem_scores.parquet).

What the GP sees

  • Input: the 161 pre-catalysts as stored (salts, free NHCs, CO₂ adducts, bicarbonates), so counter-ions are part of the graph. There is no grover_carbene counterpart, unlike the 7 models that have both variants.
  • grover: fingerprint mode, 4 × 1200 mean-pooled embeddings ‖ 200 rdkit_2d_normalized descriptors (CDF-scaled to [0, 1]), row-wise L2-normalised. 5000 columns.
  • grover_pca: StandardScaler + PCA over the 161 rows, Kneedle knee at 16 components, 92.4 % variance retained.

Decomposition I ran on the stored matrices

  • The RDKit block carries only 3.2 % of the variance in the 16 retained PCs (22 of its 200 columns are constant over the library). So grover_pca is not the descriptors in disguise.
  • However, a ridge model from the 178 non-constant RDKit 2D columns predicts the first five PCs of the 4800-d GROVER embedding alone with 5-fold CV R² = 0.95, 0.90, 0.80, 0.89, 0.83.

On this library the embedding geometry is largely a linear re-expression of classical 2D descriptors. That matches the literature above and means the paper cannot attribute the grover_pca win to self-supervised pretraining without a control.

Recommendations, in order of cost

  1. Add rdkit2d and rdkit2d_pca (the 200 columns already written by save_features.py into data/grover_tmp/features.npz) and grover_nofeat_pca (rerun the CLI without --features_path). Three cheap levels on the baseline config answer "pretraining or descriptors?", which a reviewer aware of Deng et al. (2023) will ask.
  2. Add grover_carbene for parity with the other _carbene/_precat pairs. [UNVERIFIED] Expect it to do worse: a divalent carbene carbon is rare or absent in ZINC/ChEMBL, so its context classes are off-distribution, whereas imidazolium and thiazolium cations (thiamine analogues) occur in ChEMBL.
  3. Add CheMeleon (chemprop foundation checkpoint) as a new level. Its pretraining target is Mordred descriptors, it is designed for the small-data regime, and a D-MPNN fingerprint is cheap to extract for 161 molecules. It is the most defensible 2025/26 representative in the scan.
  4. Treat TabPFN-style or Monroe in-context predictors as competing surrogates, not featurizations. They do not fit the GP/BO pipeline without a separate comparison against the GP on the same CV studies.

None of these involve electronic descriptors, so the xTB-only boundary is unaffected. Keep grover_pca as a surviving level; replacing it on literature grounds alone would ignore that it currently tops your own sweep.
